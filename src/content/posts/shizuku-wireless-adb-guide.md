上一篇《[ADB 和 root 到底是什么](/posts/android-adb-root-beginner/)》里打了个比方：**ADB 是物业给的对讲机，root 是房本钥匙。**

那篇文章结尾说过一句话：能用 ADB 解决的事，就别 root。这一篇讲的就是"怎么用 ADB 解决"——**不 root、不解锁、不丢保修**，靠一台手机、一根网线都不用，把对讲机的权限临时借给几个 App，让它们替你去干那些原本"必须有 root"才能干的事。

## 一、先看懂这条链路

整件事是三层转发：

```text
手机系统的「无线调试」  ←  提供 adb 通道（对讲机）
        ↓
     Shizuku          ←  拿到 adb 权限并常驻，替 App 转发（前台）
        ↓
Canta / SAI / Scene   ←  真正干活的 App（你家的智能面板）
```

三个角色的分工：

- **无线调试**：Android 11 起系统自带，让你不开 USB、不接电脑也能用 adb；
- **Shizuku**：把 adb 级别的权限"借"给普通 App，让 App 能调系统接口；
- **Canta / SAI / Scene**：拿到授权后，分别负责卸载预装、装分发包、调性能与冻结。

关键认知：**Shizuku 给的是 shell 权限，不是 root。** 它相当于"ADB 自己那条命"，能做的事和你在电脑上敲 `adb shell` 能做的一样多——比普通 App 大得多，但离 root 还差一层（改不了内核、动不了真正的系统分区）。

也正因为如此，**它每次重启都会失效**。这不是 bug，是这套方案的安全阀：权限是临时的，用完就收回。

## 二、第一步：打开无线调试并配对

前提：Android 11 及以上，手机和电脑（可选）在同一个 Wi-Fi。

1. 设置 → 关于手机 → 连续点「版本号」约 7 次，进开发者模式；
2. 开发者选项里，**「USB 调试」和「无线调试」两个都打开**（Shizuku 官方要求两个都开）；
3. 进入「无线调试」→ 点「使用配对码配对设备」，会弹出**6 位配对码**和一个端口；
4. 下拉通知栏，在 Shizuku 的通知里输入这 6 位码 → 配对完成。

配对**只需要做一次**。之后每次重启，只要在 Shizuku 里重新点一次「启动」，不用再配对。

如果你更喜欢在电脑上操作，也可以走命令行（需要下载 Google 的 platform-tools）：

```bash
adb pair 192.168.1.23:37123      # 端口和配对码在手机的「无线调试」页
adb connect 192.168.1.23:5555    # 上一步配对成功后，连上调试端口
adb devices                      # 看到设备就通了
```

> 注意：**配对端口**和**连接端口**是两个不同的数字，而且每次开关无线调试都会变。IP 也常变——路由器重新分配后就对不上了。

## 三、第二步：让 Shizuku 跑起来

从 [Shizuku 官网](https://shizuku.rikka.app/zh-hans/)装好，打开后选「通过无线调试启动」，按提示配对、启动，状态变成「正在运行」就可以了。

Shizuku 官方给了三种启动方式，按你的系统选：

| 方式 | 适用 | 要不要电脑 |
| --- | --- | --- |
| root 启动 | 已 root 的设备 | 不要 |
| **无线调试启动** | **Android 11+** | **不要** |
| 电脑 adb 启动 | Android 10 及以下 | 要 |

用电脑那条路的命令是（v11.2.0+）：

```bash
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

### 让它别动不动就停

Shizuku 被系统杀掉，是新手最常见的问题。官方 FAQ 里列了几条，值得先做：

- 允许 Shizuku **后台运行**、关掉它的电池优化；
- 开发者选项里打开「**停用 adb 授权超时**」；
- USB 用途设为「仅充电」。

### 各家的"暗门"

厂商 ROM 会额外拦一道，官方 FAQ 点名了几家：

| 品牌 | 要额外做什么 |
| --- | --- |
| 小米 / POCO（MIUI、HyperOS） | 开发者选项里打开「USB 调试（安全设置）」；通知样式切成「原生」 |
| OPPO / 一加（ColorOS） | 关闭「权限监控」 |
| 魅族（Flyme） | 关闭「Flyme 支付保护」 |

配对时一直卡在「正在搜索配对服务」，多半是 Shizuku 被限制后台联网了——允许它后台运行再试。

## 四、第三步：三个 App，三件不同的事

### 1. Canta：卸载预装

[Canta](https://github.com/samolego/Canta) 是专门干这个的：**不用 root，卸载系统里那些卸不掉的预装应用**。它靠 Shizuku 调系统的卸载接口，所以第一次点垃圾桶时会弹一次 Shizuku 授权，允许即可。

要先知道两件事：

- 它删的是**当前用户**下的安装，系统分区里的 APK 通常还在，所以多数情况能装回来；
- 它**不是万能橡皮擦**，删错核心组件（输入法、桌面、系统框架、证书服务）会直接让你开不了机或没法输入。

所以纪律是：

1. **先停用，别急着卸载**。停用观察三天，确认没有副作用再删；
2. 记下包名，卸载前确认这串 `com.xxx.yyy` 到底是什么；
3. 留一份 APK 或确认 Canta 的恢复功能可用；
4. 兜底命令（电脑 adb）：`adb shell cmd package install-existing --user 0 包名`。

### 2. SAI：装分发包（但要打折）

SAI（Split APKs Installer）解决的是"**一个应用被拆成好几个 APK**"的安装问题——`.apks`、`.xapk`、`.apkm` 这类包，系统安装器不认，SAI 能把它们拼起来装进去。配合 Shizuku，还能免掉"允许安装未知应用"的反复授权。

但要说实话：**SAI 已经停止更新很多年了**，对新版安卓和新格式的支持越来越差，装不上、闪退都不奇怪。如果它不灵，可以换：

- **App Manager**（开源，支持 Shizuku，功能更全但界面偏工程化）；
- **APKMirror Installer**（专门装 `.apkm`）；
- 部分新系统自带的文件管理器已能直接装 `.apks`。

### 3. Scene：性能与系统工具箱

Scene 是国内玩家常用的性能工具，能做帧率记录、应用冻结、权限管理、后台管控这类事。它有几种工作模式，**ADB 模式（靠 Shizuku 授权）是性价比最高的一档**：不用 root 就能用上帧率记录、冻结、权限管理这些核心功能，但涉及内核调度、电压、频率的功能仍然要 root。

用法就是：Shizuku 启动好 → 打开 Scene → 选 ADB 模式 → 弹出授权时选「始终允许」。

两点提醒：**不同 ROM 的兼容性差别很大**，功能显示不全不代表你装错了；另外别乱动调度和性能参数，那是真能让手机变卡的。

## 五、这件事到底该用哪一层

把上一篇的"能力对照"补全成这样一张表，照着挑就行：

| 你想做的事 | ADB | Shizuku + App | root |
| --- | --- | --- | --- |
| 卸载/冻结预装 | ✅ | ✅（Canta、Scene） | ✅ |
| 装 `.apks` / `.xapk` | ✅ | ✅（SAI、App Manager） | ✅ |
| 改 DPI、分辨率、截屏录屏 | ✅ | ⚠️ 看 App | ✅ |
| 看帧率、管后台、管权限 | ❌ | ✅（Scene） | ✅ |
| 全局 hosts 去广告 | ❌ | ❌ | ✅ |
| 完整备份应用数据（含登录态） | ❌ | ⚠️ 部分 | ✅ |
| 改内核、调度、频率 | ❌ | ❌ | ✅ |

规则很简单：**表格里 ADB 那一列能打勾的，就别装 Shizuku；Shizuku 能打的，就别 root。** 每往下一层，风险和不可逆性都高一档。

## 六、五个最容易翻车的点

1. **在公共 Wi-Fi 上开无线调试。** 等于把对讲机挂在客厅，同网段的人有机会连上来。用完就关，别常开。
2. **以为配对一次就一劳永逸。** 配对确实只做一次，但**每次重启后 Shizuku 都要重新启动**，这是系统限制。
3. **端口和 IP 变了还在用旧命令。** 无线调试的两个端口每次开关都会变，`adb connect` 失败先回去看一眼。
4. **拿主力机当试验田。** 卸载、冻结、改参数，先在旧手机或备用机上跑一遍。
5. **用来路不明的"一键优化"脚本。** 这类脚本常带改包名、刷模块的私货；官方文档里给的命令，自己抄一遍最稳。

## 七、几个常见问题

**配对时一直"正在搜索配对服务"？**
让 Shizuku 允许后台运行（很多 ROM 一切到后台就断网），再把无线调试关了重开。

**输入配对码立刻失败？**
小米系把通知样式改成「原生」，配对码是通过通知栏输入的；配对码是一次性的，超时或关掉弹窗就失效，回系统页面重新取。

**提示"adb 权限受限"？**
小米开「USB 调试（安全设置）」，ColorOS 关「权限监控」，Flyme 关「支付保护」。

**重启后 Shizuku 显示已停止？**
正常现象。打开 Shizuku 点一次「启动」，不用重新配对。

**卸载错了开不了机？**
先试 `adb shell cmd package install-existing --user 0 包名`；进不去系统就恢复出厂。这也是为什么第 3 条纪律是"先停用"。

## 最后

这套方案的妙处在于**权限是借的，不是给的**：用完重启就收回，设备始终没有真正"敞开门"。

代价是每次开机要手动点一下、部分功能受 ROM 限制、而且能做的事刚好卡在 root 之下。但只要你想要的是"把预装清干净、把分发包装上、看看帧率"，这个位置就是甜点——比 ADB 省事，比 root 安全。
