密码这件事，最省事的做法是把它们交给一个云密码库；最踏实的做法是**手里只有一个加密文件，谁也别想替你保管**。

这篇讲后者怎么做：电脑端用 [KeePassXC](https://keepassxc.org/) 建库，手机端用 [Monica Pass](https://github.com/Monica-Pass/Monica) 打开**同一份** `.kdbx` 文件。不注册账号、不上传主密码，两端编辑的是同一个文件。

不讲加密原理，只讲怎么装、怎么点、哪里会踩坑。

## 开始之前，先确认三件事

| 项目 | 要求 |
| --- | --- |
| 电脑 | Windows / macOS / Linux 都行，KeePassXC 2.8 系列 |
| 手机 | Android 8.0 及以上 |
| Monica 版本 | **至少要 1.0.323** |

最后一条是关键。Monica 从 **1.0.323（2026-10-31）** 起才支持**直接读写原始的 KDBX 库**；再早的版本只能把 `.kdbx` 一次性导入成它自己的格式，之后电脑上改了手机看不到，等于两套数据。装之前先看一眼版本号。

下载渠道只有两个，别从第三方软件站拿：

- KeePassXC：<https://keepassxc.org/download/>，Windows 用安装包，Linux 优先 Flatpak。
- Monica：<https://github.com/Monica-Pass/Monica/releases>，注意区分 `arm64-v8a`（绝大多数新手机）和 `armeabi-v7a` 两个安装包。

## 一、电脑上把库建起来

打开 KeePassXC，「数据库」→「新建数据库」，起个名字（比如 `我的密码库.kdbx`），选保存位置。

**主密码**是全库唯一的钥匙。推荐两种写法：

- 五六个互不相关的词，用空格连起来，比如"柯基 铁轨 雨伞 摩卡 竹节 灯塔"；
- 或者 20 位以上的随机串，抄一份放纸质应急包。

别用你注册其他网站时用过的密码，也别用生日、手机号做变形。

建完之后建议做两件事：

1. **「数据库」→「数据库安全」→「加密设置」**，确认数据库格式是 **KDBX 4.0**，密钥派生函数是 **Argon2id**（新版默认就是，看一眼即可）。
2. 想再稳一点，可以在同一页「添加密钥文件」，让 KeePassXC 生成一个专用密钥文件。**它绝对不能和库文件放在一起同步**，否则等于把钥匙和锁装进同一个信封。

## 二、挑一种同步方式

`.kdbx` 是加密文件，放哪都行；区别只在于"改动怎么从电脑跑到手机"。

| 方式 | 适合谁 | 备注 |
| --- | --- | --- |
| Syncthing | 愿意折腾、不想过第三方服务器 | 两台设备点对点直连，需要都在线 |
| WebDAV / 网盘 | 想省事 | 坚果云、Nextcloud、OneDrive 都行，服务端只看到密文 |
| 手动拷贝 | 只存几十条重要账号 | 数据线或局域网传一次，最保守 |

Monica 自带 WebDAV 备份和远端库同步，如果你用网盘，手机端可以直接绑定同一个路径。

不管选哪种，记住两条：

- **同一时间只让一端处于编辑状态**；
- 改完先等同步跑完，再打开另一端。

## 三、手机上打开同一份库

装好 Monica 后第一次启动，会让你设置一个 **Monica 主密码**——注意这是它自己本地库的密码，跟你的 `.kdbx` 主密码是两个东西。可以设成一样省事，也可以不一样。

然后到「同步与备份」或数据库管理里，选择导入 / 绑定那份 `.kdbx`，输入 **KDBX 主密码**。进去之后看到的就是你电脑上那份库的分组和条目，编辑保存也是直接写回原文件。

最后去手机系统设置里，把「自动填充服务」设成 Monica；再回 Monica 设置里开启指纹 / 面容解锁。**生物识别只是省去打字**，换手机、清数据之后，能救你的还是主密码。

## 四、日常怎么用

**电脑上填密码**：装 KeePassXC-Browser 扩展（Chrome / Edge / Firefox 都有），在 KeePassXC 设置里打开「浏览器集成」并和扩展配对，以后登录页直接弹候选账号，一键填充。扩展和本机 KeePassXC 之间走本地通道，不经过服务器。

**桌面软件、老客户端**：用 Auto-Type，快捷键默认 `Ctrl+Shift+V`，它会模拟键盘把账号密码敲进去。

**手机上**：登录 App 或网页时，系统自动填充会调起 Monica；遇到不认自动填充的 App，切到 Monica 键盘手动填。

**验证码**：Monica 内置 TOTP，扫码就能存，不用再装一个验证器。

## 五、十个必须注意的问题

1. **主密码忘了就是永久打不开。** 没有找回、没有客服、没有后门。这是设计，不是 bug。
2. **密钥文件丢了同样打不开。** 用了密钥文件就备份两份，且与库文件分开存。
3. **两端同时改会冲突。** 冲突后不要直接点"覆盖"：Syncthing 会留下 `.sync-conflict-日期.kdbx`，网盘常留 `(conflicted copy)` 副本，把两份都留着，再用 KeePassXC 合并。
4. **Monica 版本太老等于白干。** 1.0.323 之前只能一次性导入，电脑上的改动它看不见。
5. **Monica 是第三方开源应用，不是 KeePassXC 官方出品。** 官方推荐的安卓客户端其实是 KeePassDX 和 KeePass2Android。选 Monica 是因为它把 KDBX、TOTP、自动填充和备份放进了一个应用；介意这一层的话，把手机端换成 KeePassDX，电脑端的做法完全不用改。
6. **别把密码和验证码放同一个库。** 两者同库，等于把"两个因素"合并成了一个。验证码可以放到另一个库，用不同主密码。
7. **Linux 的 Wayland 桌面下没有 Auto-Type。** 只能在 X11 会话里用，别指望它在 Ubuntu 新装的默认会话里工作。
8. **部分小米 HyperOS 机型上 Monica 建不了通行密钥**，这是系统兼容性问题，和密码库本身无关。
9. **升级 Monica 前先备份。** 直接管原库这个能力比较新，重要库别拿唯一的文件当试验品。
10. **备份要真的打开验证过才算备份。** 每月把离线备份拷到另一台机器，用主密码打开一次——这十分钟比任何参数都值钱。

## 小结

这套方案的门槛只有两个：**记住一个主密码，接受两端不要同时写**。换来的是：没有公司能一次性拿走你的全部账号，也没有哪天开始收费或关停的风险。

如果你已经在用 KeePassXC，只是嫌手机上填密码麻烦，那 Monica 1.0.323 之后"直接读写原库"的能力，正好补上了最后一块短板。
